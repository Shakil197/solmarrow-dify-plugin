# Privacy

This plugin connects Dify to your SolMarrow account (https://solmarrow.com).

**What it sends.** Only what a tool call needs, to `https://app.solmarrow.com/api/v1`, and nowhere else: your API key (as a Bearer token), post text, account/media/post ids, times, and media URLs you ask it to upload.

**What it stores.** Nothing. The plugin keeps no data and writes no logs. Your API key is held by Dify as a credential.

**What SolMarrow does with it.** Posts, media and analytics live in your SolMarrow workspace under SolMarrow's privacy policy: https://solmarrow.com/privacy

**Control.** Delete the API key in SolMarrow (Settings → Apps and AI agents → API keys) to cut access at once.

Contact: support@solmarrow.com
